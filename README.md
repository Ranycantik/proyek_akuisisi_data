Tujuan

Praktikum ini bertujuan memahami proses akuisisi data, penyimpanan, pembersihan, transformasi, analisis, dan penyajian data.

Struktur Folder

- "data/raw": menyimpan data mentah.
- "data/interim": menyimpan data sementara.
- "data/processed": menyimpan data yang siap dianalisis.
- "notebooks": menyimpan notebook praktikum.
- "src": menyimpan kode Python.
- "docs": menyimpan dokumentasi dan tabel lifecycle.
- "reports": menyimpan laporan praktikum.

Cara Menjalankan

1. Buka notebook menggunakan Google Colab.
2. Jalankan setiap sel kode secara berurutan.
3. Periksa hasil pemeriksaan library dan tabel Data Science Lifecycle.

Tools

Python, Google Colab, Pandas, NumPy, Requests, BeautifulSoup, dan GitHub.
